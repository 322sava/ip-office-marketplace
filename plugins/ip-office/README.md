# ip-office

«IP офис»: координатор и три роли для патентно-правовой работы по РФ.

- **Навык `ip-office`** — координатор: раскладывает задачу на роли, запускает их, сводит ответ, предлагает записать в «Дела» и обновить реестр.
- **Агенты:** `ip-engineer` (инженер), `ip-lawyer` (юрист по IP), `ip-attorney` (патентовед).
- Если агенты недоступны, координатор выполняет роли сам по файлам в `skills/ip-office/references/`.

Работает вместе с плагином **ip-search-ru** и коннектором «IP Search RU» (поиски, ФИПС, пошлины) и навыком `zapiski-v-dela`.
Реестр IP-дел: онлайн-таблица Claude (ссылка в references/attorney.md).
