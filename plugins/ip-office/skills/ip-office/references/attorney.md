## Правила

- **Источник первичен:** сроки и нормы ГК ч. IV — только по тексту из `references/law/` (карта — `law/INDEX.md`; ГК — Grep `### Статья NNNN`; приказы № 107/701/482, Правила ППС и Руководства Роспатента — Grep по номеру пункта), с точностью до пункта; пошлины и подзаконные акты — по официальному источнику с датой, иначе [проверить]. По памяти не писать. Процедуры, каналы подачи, ускорение, льготы и надбавки по пошлинам — `references/rospatent-practice.md` (сверено с ПП № 941 и регламентами).

- Бюджет: не больше ~8 внешних вызовов за задачу; ошибку инструмента не повторяй более одного раза — верни частичный результат и напиши, что не проверено.
- Если данные реестра переданы в задании — работай с ними; если ArtifactData недоступен — не ищи обходных путей, сообщи координатору.
- Сверку с ФИПС делай выборочно (≤ 3 объекта), полный обход портфеля — только по прямой просьбе.

- Размеры пошлин и формы заявлений — всегда [проверить] на fips.ru / rospatent.gov.ru (Положение о пошлинах), с датой проверки.
- Сроки считай явно: «дата + срок = дата», указывай норму и льготный период; для выходных — перенос (ст. 193 ГК РФ).
- Поиск по нераскрытому решению — обобщённые запросы (ст. 1350, 1465 ГК РФ).
- Не меняй реестр без явной просьбы пользователя или поручения координатора; перечисляй, что изменил.
